🌟 Sistema de Patrocínio de Grupos - Guia Frontend

📋 Response da Criação de Grupo

Ao criar um grupo, o backend retorna sponsorshipInfo:

{
  "id": "group-123",
  "name": "Meu Grupo",
  "status": "PENDING",
  "sponsorshipInfo": {
    "canSponsor": true,
    "activeSponsoredCount": 2,
    "maxAllowed": 5
  }
}

🎯 Estados e Avisos

1️⃣ Pode Patrocinar

Condição: canSponsor: true
Mensagem: "✅ Este grupo pode ser patrocinado!"
Ação: Oferecer upgrade/plano de patrocínio

2️⃣ Limite Atingido

Condição: canSponsor: false + activeSponsoredCount: 5
Mensagem: "⚠️ Você atingiu o limite de 5 grupos patrocinados.
Este grupo será gratuito. Atualize seu plano para patrocinar mais grupos."
Ação: Botão "Fazer Upgrade" → Redirecionar para planos

3️⃣ Sem Plano Ativo

Condição: canSponsor: false + activeSponsoredCount: 0
Mensagem: "💡 Este grupo será gratuito. Adquira um plano de patrocínio para destacá-lo!"
Ação: Botão "Ver Planos" → Mostrar opções (3, 7, 15, 30 dias)

🔄 Fluxo Recomendado

  1. Criar Grupo → POST /api/v1/groups
  2. Verificar Response:
    • Se canSponsor === true: Perguntar se quer patrocinar agora
    • Se canSponsor === false: Avisar com mensagem amigável
  3. Mostrar Badge no Card:
    • Se patrocinado: 🌟 PATROCINADO
    • Se não patrocinado: nada ou Gratuito

📊 Integração com GET /limits

{
  "canSponsor": true,
  "sponsoredGroups": {
    "active": 2,
    "max": 5,
    "remaining": 3
  }
}

Use isso para mostrar barra de progresso:

Grupos Patrocinados: 2/5 ⬜⬜⬜⬜⬜
Espaço disponível: 3

⚡ Casos de Erro

try {
  const group = await createGroup(data);

  if (!group.sponsorshipInfo.canSponsor) {
    showWarning(
      `Limite atingido:
       ${group.sponsorshipInfo.activeSponsoredCount}/
       ${group.sponsorshipInfo.maxAllowed}`
    );
  }
} catch (error) {
  showError(error.message);
}
